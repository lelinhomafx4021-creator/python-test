# README 图片目录

把准备展示在 GitHub README 里的截图放到这个目录里。

推荐命名方式：

- `login.png`
- `dashboard.png`
- `chat.png`
- `watchlist.png`
- `paper-trading.png`
- `handoff-ticket.png`

根目录 `README.md` 里可以这样引用：

```md
![聊天页](./docs/images/chat.png)
```

或者：

```html
<img src="./docs/images/chat.png" alt="chat" width="900" />
```

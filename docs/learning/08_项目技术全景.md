### 1. AOP（面向切面编程）

**是什么：** 不改原有代码，给方法"插一脚"——加日志、加鉴权、加限流。

**解决什么问题：**
```java
// 没有 AOP：每个 Controller 都要写一遍登录检查
@GetMapping("/quotes")
public Result quotes() {
    checkLogin();  // 重复代码
    return ...;
}

@GetMapping("/orders")
public Result orders() {
    checkLogin();  // 又写一遍
    return ...;
}

// 有 AOP：一行注解搞定
@LoginRequired
@GetMapping("/quotes")
public Result quotes() { return ...; }
```

**项目里用在哪：**
- `@LoginRequired` — 登录拦截
- AI 审计日志
- 接口耗时统计

**核心概念：**
- 切面（Aspect）= 要插入的逻辑
- 切入点（Pointcut）= 在哪里插入
- 通知（Advice）= 插入的时机（之前/之后/环绕）

### 2. Sa-Token（登录鉴权）

**是什么：** 轻量级权限认证框架，替代复杂的 Spring Security。

**解决什么问题：**
```java
// 没有框架：手动取 Token → 查 Redis → 判断过期
String token = request.getHeader("satoken");
Object userId = redis.get("token:" + token);
if (userId == null) throw new NotLoginException();

// 有 Sa-Token：一行搞定
@LoginRequired  // 或 StpUtil.checkLogin()
```

**项目里用在哪：**
- 登录/注销
- Token 管理（超时、并发登录控制）
- `@LoginRequired` 注解底层就是 Sa-Token

**核心概念：**
- StpUtil — 登录工具类（login/logout/checkLogin/getLoginId）
- Token — 登录凭证（UUID 风格）
- 会话 — Sa-Token 管理的登录状态

---

### 3. RabbitMQ（消息队列）

**是什么：** 异步通信中间件。A 把消息扔进队列，B 异步取出来处理。

**解决什么问题：**
```
没有 MQ（同步）：
用户发消息 → 保存DB → 调AI审计 → 推送通知 → 返回
                 每一步都等上一步完成，慢

有 MQ（异步）：
用户发消息 → 保存DB → 扔进MQ → 立即返回
                         ↓
                    消费者慢慢处理（审计、通知）
```

**项目里用在哪：**
- AI 对话审计（异步记录到 DB）
- 交易事件通知
- 解耦业务模块

**核心概念：**
- Producer — 生产者（发消息）
- Consumer — 消费者（收消息）
- Exchange — 交换机（决定消息发给哪个队列）
- Queue — 队列（存消息的地方）
- Routing Key — 路由键（消息的标签）

---

### 4. Flyway（数据库版本管理）

**是什么：** 像 Git 管理代码一样管理数据库表结构。

**解决什么问题：**
```
没有 Flyway：
开发小王改了表结构 → 开发小李不知道 → 代码报错
手动执行 SQL 脚本 → 容易漏、容易乱

有 Flyway：
SQL 脚本放在 resources/db/migration/
V1__create_user_table.sql
V2__add_email_column.sql
启动时自动按版本号顺序执行，执行过的不会重复执行
```

**项目里用在哪：**
- 表结构迁移（建表、加字段、改索引）

**核心概念：**
- 迁移脚本命名：`V1__描述.sql`（两个下划线）
- 自动执行：启动时检测未执行的脚本并执行
- 版本记录：flyway_schema_history 表记录已执行的脚本

---

### 5. Sentinel（流量控制）

**是什么：** 阿里开源的流量控制框架，防止系统被突发流量打垮。

**解决什么问题：**
```
没有 Sentinel：
秒杀活动 → 10万人同时请求 → 数据库崩了 → 全站挂掉

有 Sentinel：
秒杀活动 → 限制每秒最多 1000 请求 → 多的排队或拒绝
         → 数据库正常 → 已进入的用户正常服务
```

**项目里用在哪：**
- 行情接口限流（20 QPS）
- 模拟交易限流（10 QPS）
- AI 流式对话限流（8 QPS）

**核心概念：**
- 资源（Resource）= 要保护的接口
- 规则（Rule）= 限制条件（QPS、并发数）
- 降级（Degrade）= 超限时的兜底方案
- Dashboard = 控制台（可视化配置规则）

---

### 6. Aliyun OSS（云存储）

**是什么：** 阿里云对象存储，上传文件存到云端。

**解决什么问题：**
```
没有 OSS：
用户上传头像 → 存服务器本地磁盘 → 磁盘满了、换服务器文件丢了

有 OSS：
用户上传头像 → 直接传到阿里云 → 返回 URL → 存 URL 到数据库
```

**项目里用在哪：**
- 用户头像上传

### 7. LangGraph（AI Agent 状态图）

**是什么：** LangChain 出品的 AI Agent 编排框架，用"图"定义多步推理流程。

**解决什么问题：**
```
普通 AI 对话：
用户问 → AI 直接答（一步到位）

LangGraph：
用户问 → 判断意图 → 调行情API → 搜索知识库 → 综合分析 → 生成回答
         ┌→ 行情节点 ─┐
         │            ↓
开始节点 ─┤     综合分析节点 → 输出
         │            ↑
         └→ RAG节点 ──┘
```

**项目里用在哪：**
- 投研对话编排（多步推理）
- 状态持久化（PostgreSQL checkpoint）

**核心概念：**
- StateGraph — 状态图定义
- Node — 节点（一个处理步骤）
- Edge — 边（节点之间的连接）
- State — 状态（节点之间传递的数据）
- Checkpoint — 检查点（状态持久化，支持断点续聊）

### 8. RAG（检索增强生成）

**是什么：** 先从知识库搜相关内容，再让 AI 基于搜索结果回答。

**解决什么问题：**
```
没有 RAG：
用户问 "茅台的财报怎么样" → AI 凭训练数据瞎猜

有 RAG：
用户问 "茅台的财报怎么样"
  → 先搜知识库，找到相关文档片段
  → 把片段喂给 AI："根据以下资料回答..."
  → AI 基于真实资料回答
```

**项目里用在哪：**
- 知识库问答（研报、公告等文档）

**核心概念：**
- 文档解析（PDF/Word → 文本）
- 分块（长文本切小段）
- 向量化（文本 → 数组，用 pgvector 存储）
- 检索（用户问题 → 找最相关的文本片段）
- 生成（把片段 + 问题一起给 AI）

---

### 9. pgvector（向量数据库）

**是什么：** PostgreSQL 的扩展，支持存储和搜索向量（文本的"语义指纹"）。

**解决什么问题：**
```
传统搜索：关键词匹配
"股票下跌" → 找包含"股票"和"下跌"的文章

向量搜索：语义相似
"股价走低" → 找到语义相近的文章（即使没出现"走低"这个词）
```

**核心概念：**
- 向量（Embedding）：把文本变成一串数字 [0.12, -0.34, 0.56, ...]
- 余弦相似度：两个向量越接近，语义越相似
- pgvector 存在 PostgreSQL 里，不用额外部署

---

### 10. Langfuse（LLM 可观测性）

**是什么：** LLM 调用链追踪工具，看 AI 每一步干了什么。

**解决什么问题：**
```
没有 Langfuse：
用户问 → AI 回答错误 → 不知道哪一步出了问题

有 Langfuse：
用户问 → [Langfuse 记录]
         ├─ 意图识别：投研查询 ✓
         ├─ 调行情 API：返回 600519 数据 ✓
         ├─ RAG 检索：找到 3 条相关文档 ✓
         ├─ 生成回答：引用了错误的文档 ✗ ← 这里出问题了
```

**项目里用在哪：**
- 记录每次 AI 对话的完整链路
- 监控 Token 消耗、响应时间
- 排查 AI 回答质量问题

---

### 11. ECharts（前端图表库）

**是什么：** 百度开源的 JS 图表库，支持几十种图表类型。

**项目里用在哪：**

- 收益曲线（折线图）

### 12. Tailwind CSS（原子化 CSS）

**是什么：** 不写 CSS 文件，直接在 HTML 里用类名组合样式。

```html
<!-- 传统 CSS -->
<button class="btn-primary">按钮</button>
<!-- 要去 CSS 文件里写 .btn-primary { ... } -->

<!-- Tailwind -->
<button class="bg-blue-500 text-white px-4 py-2 rounded">按钮</button>
<!-- 直接在类名里写样式，不用写 CSS 文件 -->
```

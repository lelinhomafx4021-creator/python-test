# 12 - CDN（内容分发网络）

## 一、CDN 是什么

**一句话：把你的文件复制到全国各地的服务器上，用户就近下载。**

```
没有 CDN：
  你的服务器在北京
  上海用户下载 → 请求跑到北京 → 再返回上海
  广州用户下载 → 请求跑到北京 → 再返回广州
  距离越远，速度越慢

有 CDN：
  你的文件复制到了 北京、上海、广州、成都 的服务器上
  上海用户下载 → 直接从上海服务器取 → 快
  广州用户下载 → 直接从广州服务器取 → 快
```

## 二、核心原理

```
┌─────────────────────────────────────────────────────────┐
│                    CDN 工作原理                           │
│                                                         │
│  用户请求文件                                            │
│    │                                                    │
│    ▼                                                    │
│  DNS 智能解析                                            │
│    │ "这个用户在上海，给他分配上海的 CDN 节点"             │
│    ▼                                                    │
│  上海 CDN 节点                                           │
│    │                                                    │
│    ├─ 有缓存 → 直接返回（快！）                          │
│    │                                                    │
│    └─ 没缓存 → 回源站取 → 缓存一份 → 返回给用户          │
│                    │                                    │
│                    ▼                                    │
│              源站（你的 OSS/服务器）                      │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 三个角色

| 角色 | 是什么 | 项目里对应 |
|------|--------|-----------|
| **源站** | 文件的原始存储位置 | 阿里云 OSS |
| **CDN 节点** | 分布在全国各地的缓存服务器 | 阿里云 CDN 边缘节点 |
| **DNS 智能解析** | 根据用户位置分配最近的节点 | 阿里云 DNS |

## 三、类比：快递仓库

```
没有 CDN = 只有一个仓库（北京）
  上海买家下单 → 从北京发货 → 3 天到
  广州买家下单 → 从北京发货 → 4 天到

有 CDN = 全国有多个仓库
  上海买家下单 → 从上海仓库发货 → 当天到
  广州买家下单 → 从广州仓库发货 → 当天到

源站 = 总仓库（只有一份正品）
CDN 节点 = 各地分仓（从总仓库调货，本地存一份）
```

## 四、访问流程（完整）

### 第一次访问（冷命中）

```
用户在上海，请求 https://cdn.example.com/avatars/1/photo.jpg
  │
  ▼
① 浏览器问 DNS：cdn.example.com 的 IP 是什么？
  │
  ▼
② 阿里云 DNS 看用户在上海 → 返回上海 CDN 节点的 IP
  │
  ▼
③ 浏览器请求上海 CDN 节点
  │
  ▼
④ 上海 CDN 节点：没有这个文件（缓存未命中）
  │
  ▼
⑤ CDN 回源请求 OSS（源站）
  │
  ▼
⑥ OSS 返回文件给 CDN
  │
  ▼
⑦ CDN 缓存一份，同时返回给用户
  │
  ▼
⑧ 用户收到文件（慢了一点，因为要回源）
```

### 第二次访问（缓存命中）

```
同一个用户（或上海其他用户）请求同一个文件
  │
  ▼
① DNS 返回上海 CDN 节点 IP
  │
  ▼
② 上海 CDN 节点：有这个文件！（缓存命中）
  │
  ▼
③ 直接返回给用户（不回源，非常快）
```

## 五、CDN 的关键指标

### 1. 命中率

```
命中率 = 缓存命中次数 / 总请求次数

命中率 90% = 100 次请求里 90 次直接从 CDN 返回，只有 10 次回源
命中率越高 → 越快、越省源站带宽
```

### 2. 回源

```
回源 = CDN 没有缓存，去源站取

回源率高说明：
  - 缓存过期时间太短
  - 文件太多/太大，CDN 存不下
  - 第一次访问某个冷门文件
```

### 3. 缓存过期时间（TTL）

```
CDN 缓存的文件不是永远有效的，有 TTL（Time To Live）

静态图片：TTL = 30 天（不常变）
CSS/JS：TTL = 7 天（偶尔更新）
HTML：TTL = 1 小时（经常变）

过期后下次访问会回源，取到新版本再缓存
```

### 4. 带宽

```
CDN 带宽 = CDN 能同时给多少用户传文件

小网站：10 Mbps 够用
大网站：10 Gbps+
按量付费：用多少付多少
```

## 六、CDN 能加速什么

```
✅ 静态资源（最适合）
   图片、CSS、JS、字体、视频、安装包
   → 不常变，缓存效果好

⚠️ 动态 API（不适合）
   /api/v1/market/quotes（每次返回不同数据）
   → 缓存了也没用，每次都得回源

❌ 需要登录的接口
   /api/v1/users/me（每个用户数据不同）
   → 不能缓存
```

## 七、阿里云 OSS + CDN 配置

### 不用 CDN（直连 OSS）

```
用户 → https://package5.oss-cn-beijing.aliyuncs.com/photo.jpg
       ↓
       OSS（只有北京一个节点）
       ↓
       上海用户：慢
       广州用户：更慢
```

### 用 CDN

```
用户 → https://cdn.your-domain.com/photo.jpg
       ↓
       DNS 智能解析 → 分配最近的 CDN 节点
       ↓
       上海 CDN 节点（有缓存）→ 直接返回，快！
```

### 配置步骤

```
1. 阿里云控制台 → CDN → 添加加速域名
   加速域名：cdn.your-domain.com
   源站类型：OSS 桶
   源站地址：package5.oss-cn-beijing.aliyuncs.com

2. 配置 CNAME（域名解析）
   cdn.your-domain.com → package5.oss-cn-beijing.aliyuncs.com.cdn.dnsv1.com

3. 配置缓存规则
   .jpg/.png/.gif → 缓存 30 天
   .css/.js       → 缓存 7 天
   .html          → 不缓存

4. 完成
   访问 https://cdn.your-domain.com/photo.jpg
   → 自动走 CDN 加速
```

## 八、CDN vs 直连 OSS 对比

| | 直连 OSS | OSS + CDN |
|---|---|---|
| 访问速度 | 取决于用户到 OSS 的距离 | 全国都快（就近访问） |
| 带宽成本 | OSS 按流量计费 | CDN 按流量计费（通常更便宜） |
| 回源流量 | 无 | 有（缓存未命中时回源） |
| 适用场景 | 小文件、访问量少 | 大文件、全国用户、高访问量 |
| 配置复杂度 | 低 | 中（要配 CNAME） |

## 九、CDN 的安全机制

### 1. 防盗链（Referer 白名单）

```
只允许你的网站域名引用 CDN 资源
别人直接用你的 CDN 链接 → 拒绝

配置：
  允许：*.your-domain.com
  拒绝：其他所有域名
```

### 2. URL 鉴权（签名）

```
访问 CDN 资源需要带签名参数
https://cdn.your.com/photo.jpg?sign=xxxxx&expire=1715760000

签名过期后链接失效，防止盗链
```

### 3. HTTPS

```
CDN 支持 HTTPS 加密传输
配置 SSL 证书即可
```

## 十、常见 CDN 服务商

| 服务商 | 特点 |
|--------|------|
| 阿里云 CDN | 国内节点最多，和 OSS 无缝集成 |
| 腾讯云 CDN | 性价比高，和腾讯云生态集成 |
| Cloudflare | 免费额度大，海外节点多 |
| AWS CloudFront | 海外首选，和 S3 集成 |

## 十一、30 秒面试话术

> "项目用阿里云 OSS 存储用户头像和静态资源，通过 CDN 加速分发。用户访问时 DNS 智能解析分配最近的 CDN 节点，缓存命中直接返回，未命中回源到 OSS 取。配置了 30 天缓存 TTL 和 Referer 防盗链。好处是全国用户访问速度一致，源站带宽压力小，而且 CDN 流量费比 OSS 直接出口便宜。"

## 十二、一句话总结

**CDN = 把文件缓存到离用户最近的服务器上，就近取，不回源站。** 静态资源必用，动态 API 不适合。

# 23 - VSCode 快捷键速查

## 当前文件内

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+F` | 搜索 |
| `Ctrl+H` | 搜索替换 |
| `Ctrl+D` | 选中下一个相同词 |
| `Ctrl+Shift+L` | 选中所有相同词 |
| `Ctrl+Shift+O` | 函数/类/变量列表（输入 `@:` 按类型分组） |
| `F12` | 跳到定义 |
| `Shift+F12` | 查看引用 |
| `F2` | 重命名 |
| `Ctrl+/` | 注释 |
| `Alt+↑/↓` | 移动整行 |
| `Ctrl+Shift+K` | 删除整行 |
| `Ctrl+G` | 跳到第 N 行 |

## 跨文件（全局）

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+P` | 快速打开文件 |
| `Ctrl+Shift+F` | 全局搜索（可限定 `*.py`） |
| `Ctrl+T` | 全局搜函数/类名 |
| `Ctrl+Tab` | 切换上一个文件 |

## 其他

| 快捷键 | 作用 |
|--------|------|
| `` Ctrl+` `` | 终端 |
| `Ctrl+B` | 侧边栏 |
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+Shift+I` | 格式化代码 |

# Features

## 核心业务模块

### 账号与会员

- 登录、注册、用户资料
- 会员状态与功能配额
- 基于身份控制 AI 能力和业务权限

### 行情与资讯

- 个股查询
- 板块与热点信息
- 行情接口统一从网关进入，便于限流与缓存

### 自选股

- 自选分组
- 个股收藏与备注
- 与行情模块联动展示

### 模拟交易

- 账户初始化
- 持仓、订单、资金流水
- 面向“投资工作台”场景补齐业务闭环

### AI 投研

- SSE 流式问答
- LangGraph 工作流编排
- RAG 检索增强
- 回答质量评审

### 人工兜底

- AI 无法稳定回答时转人工
- 工单进入管理端处理
- 结果回流原会话

## 5 分钟演示路线

1. 登录系统，展示会员信息和工作台首页。
2. 打开行情模块，演示基础业务能力不是空壳。
3. 进入 AI 会话，展示流式回答而不是整段等待。
4. 说明 Java 网关会记录历史、补齐 `traceId`、透传到 Python。
5. 触发人工兜底，展示“AI 不确定时如何进入人工闭环”。
6. 最后补一句中间件职责：Redis 做缓存，RabbitMQ 做异步审计，Postgres/pgvector 做 AI 侧状态和检索。

## 面试时别讲成什么

- 不要讲成“我接了一个大模型接口”。
- 不要把所有亮点都压在 LangGraph 上。
- 不要把中间件说成“为了炫技加的”。

## 更适合的讲法

- 这是一个有业务边界的 AI 应用，不是纯聊天 Demo。
- Java 保证业务系统稳定，Python 负责 AI 编排和快速迭代。
- 小而值钱的工程点比“上集群”更适合实习面试项目。

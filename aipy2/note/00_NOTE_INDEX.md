## 你应该先建立的三个核心认知

1. 这个项目不是“用户一句话直接问大模型”，而是一个带工作流、带检索、带评审回退的 Agent 系统。
2. 当前它更准确叫“单 Agent + 多节点工作流”，不是严格意义的多智能体。
3. 真正值得学的不是某个 API 名字，而是分层思想：入口层、配置层、编排层、状态层、检索层、存储层、流式层如何协作。

## 读法建议

1. 每看完一篇，都试着自己画图。
2. 每看完一个模块，都用 Java 类比复述一遍。
3. 不要一上来就纠结每一行代码，先抓“这层为什么存在”。

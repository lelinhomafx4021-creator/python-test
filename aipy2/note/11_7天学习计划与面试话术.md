## 90 秒面试话术

> 这个 Python 项目是一个基于 FastAPI 和 LangGraph 的投研 Agent 系统。它不是简单把用户问题丢给大模型，而是先做意图判断，决定是否走 RAG。如果需要检索，会先改写 query，再并发执行向量检索、BM25 和 Web 搜索，并结合行情技能拿到证据，然后由 answer 节点生成回答，再由 critic 节点做质量评审，不通过则回退重试。整个过程通过 SSE 流式向前端推送思考步骤和正文增量，同时把关键会话和审计信息落到数据库。架构上我重点做了模型适配层、状态化工作流、流式链路和检索融合这几部分。

## 你回头复习时最实用的方法

1. 每天只攻一个主题
2. 每个主题都先讲“为什么有这层”
3. 每看完一个点都试着脱稿复述

## 这一篇你最该记住的结论

1. 学习 Agent 项目不要贪快，要按层次来。
2. 最有含金量的不是记住 API，而是能解释设计动机。
3. 你只要能把这 7 天计划走完，已经能明显超过“只会调模型接口”的水平。

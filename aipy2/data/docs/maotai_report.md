# 贵州茅台 (600519) 2024 年一季度投资价值分析报告

## 核心结论
贵州茅台作为 A 股白酒龙头，其品牌护城河极深。2024 年一季度公司实现营业收入 464.8 亿元，同比增长 18.04%；归母净利润 240.7 亿元，同比增长 15.73%。业绩增长稳健，财务指标极其健康。

## 业务亮点
1. **i 茅台平台贡献显著**：直销渠道占比持续提升，有效平抑了渠道成本，提升了利润率。
2. **产品矩阵完善**：茅台 1935 等系列酒表现亮眼，成为公司第二增长曲线。
3. **产能扩充有序**：茅台酒和系列酒的扩产项目正在按计划推进，为未来销量增长提供基础。

## 财务指标分析
- **毛利率**：维持在 91% 以上的高位。
- **净利率**：保持在 50% 左右，盈利能力极强。
- **预收款项**：合同负债充足，体现了下游经销商的强劲需求。

## 投资风险提示
1. **宏观经济波动**：消费降级可能影响高端白酒的销量。
2. **政策风险**：白酒行业监管政策变化可能对估值产生影响。
3. **渠道改革风险**：直销转型过程中与传统经销商的利益分配问题。
